**Word Forms 2/10 是七科里最低的单一 section。**

### Word Forms 是规则题，不是语感题

你错的两题：
- `civilisation` → **civilisations**（漏了复数）
- `historicst` → **historians**（这不是一个英文词）

**三步法，每一题都走完：**
1. 看空格**前后**判词性
   `the ___ of` → 名词／`a ___ noun` → 形容词／`to ___` → 动词／`___ly` → 副词
2. 想词根 ＋ 对应后缀（-tion / -sion / -ist / -ian / -ment / -ness / -ity / -ous / -ive）
3. **最后一步：查单复数、查时态、查主谓一致** ← 你漏的就是这一步

### Error Identification 也是五类
预考错的 Q32、33、34、35、39 **全部落在这五类**：
时态 · 主谓一致 · 冠词 · 介词 · 从句连接词

一天一类，各做 20 题。
