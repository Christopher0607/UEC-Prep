## 微分 · 什么时候用哪条法则

看到 y ＝ 两个含 x 的东西相乘（如 x²·√(x²−1)）|乘积法则：先设 u、v，再写 u′v ＋ uv′。两项写完才合并，别边微分边合并
看到 y ＝ 分子分母都含 x 的分式|先看能不能化简成和式（能就别用商法则）；不能才用商法则 (u′v − uv′)/v²
看到 y ＝ 整个括号带次方，如 (x²−1)^n 或 √(x²−1)|链式法则：先对整块微分成 n(...)^(n−1)，**再乘括号内部的导数**。漏掉「再乘内部」是最常见的丢分
看到 √(某个含 x 的式子)|先改写成 (...)^(1/2) 再微分。带着根号做最容易漏链式那一步
乘积法则做完，两项一项带 √ 一项带 1/√，要合并|通分到同一个 √ 分母：2x√(x²−1) ＝ 2x(x²−1)/√(x²−1)。**分子展开后逐项核对次方** —— 预考 Q17 就错在这里，(3x³−2x) 被写成 (3x³−2x²)
题目问「切线的斜率」|dy/dx 代入该点，**算到这里就结束**
题目问「法线的斜率」|dy/dx 代入该点 → **再取负倒数**。切线 4 → 法线 −1/4。预考 Q18 停在 4 就圈了答案
题目问「切线／法线的方程」|先求斜率（法线记得取负倒数），再用 y − y₁ ＝ m(x − x₁)
题目给了点 (a, b) 又给曲线|下笔前先把 x ＝ a 代进曲线，确认这点真在曲线上。对不上就是抄错数了
题目问「曲线的转折点／最大值最小值」|令 dy/dx ＝ 0 解 x。**注意：这是求驻点，不是求斜率。** 题目问斜率时不要令它等于 0
求出驻点后要判断是极大还是极小|二阶导数：d²y/dx² > 0 → 极小；< 0 → 极大

## 积分 · 先化简再积分

看到 ∫ 分式，分子分母都含 x|**先把分式拆开化简成一串 xⁿ 的和**，再逐项积分。分子分母各自积分是无效的 —— 预考 Q19 就是这么丢的
看到 ∫ (√x + 2)/√x dx|除以 √x 就是每一项各除一次：＝ ∫ (1 ＋ 2x^(−1/2)) dx ＝ x ＋ 4√x ＋ C
积分出现常数项 1|∫1 dx ＝ x，**不是 x²**。x² 是 ∫2x dx 的结果
积分 x^(−1/2)|x^(1/2) ÷ (1/2) ＝ 2√x。所以 ∫2x^(−1/2) dx ＝ 4√x
不定积分写完|**检查有没有 ＋C**。选项里通常有一个只差 C 的陷阱
看到 ∫ 上下限都是数字（定积分）|不用写 C。代上限减下限
看到 ∫ₐᵇ [k·f(x) ＋ c] dx 这种线性组合|拆开：k∫ₐᵇf(x)dx ＋ c(b−a)。**常数项积分出来是 c×(上限−下限)**，不是 c
看到 ∫₁¹⁰ 和 ∫₃¹⁰ 要求 ∫₁³|区间相加性：∫₁³ ＝ ∫₁¹⁰ − ∫₃¹⁰。先把已知的那个解出来
∫₃¹⁰[2f(x)−3]dx ＝ 51，求 ∫₃¹⁰f(x)dx|2∫f − 3×(10−3) ＝ 51 → 2∫f − 21 ＝ 51 → ∫f ＝ 36。**常数那一项别忘了乘区间长度 7**

## 指数与根式（预考 Q3 丢的那一类）

看到根号套根号，如 √(b/√(a⁵))|**一律先换成分数指数再算**。√(a⁵) ＝ a^(5/2)，整块 ＝ (b·a^(−5/2))^(1/2) ＝ b^(1/2)·a^(−5/4)
看到 (...)^m 外面还有次方 n|指数相乘：a^(m·n)。(b^(1/2)a^(−5/4))⁴ ＝ b²a^(−5)
看到 ∛(a²/b) 的 6 次方|(a^(2/3)b^(−1/3))⁶ ＝ a⁴b^(−2)
两块相乘，同底数|指数相加。b²a^(−5) × a⁴b^(−2) ＝ a^(−1)b⁰ ＝ **a⁻¹**
化简到最后|检查每个字母的指数**是不是都算到零或一个干净的整数**。选项里常有一个「b 没消掉」的陷阱

## 对数（预考 Q8 蒙对的那一类，要补）

看到 log 的底数不统一（log₇5 · log_{x²}49 · log₂₅x）|**全部换底成 ln 或 lg**：log_b a ＝ ln a / ln b。换完之后分子分母大量对消
看到 log_{x²}49|49 ＝ 7²，x² 的指数也提出来：＝ 2ln7 / 2ln x ＝ ln7/ln x
换底后一长串分式相乘|按顺序约分，**每约掉一项就划掉**。答案往往是 1/2、1、2 这种干净的数
题目写「If x > 0」|提示你不必讨论定义域，放心约分

## 三角象限（预考 Q9 蒙对的那一类，要补）

θ 在第三象限|cos θ 与 sin θ **都是负的**，且都在 (−1, 0) 之间
问 (−1 ＋ cos θ, −1 ＋ sin θ) 在哪个象限|两个坐标都是 −1 加一个 (−1,0) 的负数 → 都落在 (−2, −1) → 两个都负 → **第三象限**
判断象限的通法|不要背口诀，**代一个具体角进去**。第三象限取 θ ＝ 210°，cos ＝ −0.87、sin ＝ −0.5，代进式子看符号
