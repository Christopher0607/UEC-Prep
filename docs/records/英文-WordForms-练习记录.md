### 一、最大的问题写在答案纸上：候选清单

你每格写两三个候选，再圈一个。看看圈掉的是什么：

- **Q36**：第一个写的是 `divitions` —— **词性是对的**（只差拼法），最后圈了 `divided`
- **Q38**：清单上写了 `rooted` —— **那就是正解**，最后圈了 `roots`
- **Q39**：列了 economist、economics、economical —— 三个都是从词根变出来的，**没有一个是先判词性得出的**

候选清单就是「被词根牵着走」写在纸上：先从词根变出几个形状，再凭语感挑。
**这个习惯要直接停掉。**

### 二、七道错题，判词性表都能直接判出来

| 表的哪一行 | 错的题 |
|---|---|
| `___ + 名词` → 形容词 | **39、42、44**（一份卷在同一行错三题） |
| `___ + 动词` → 副词 | 45 |
| `be + (副词) + ___` → 过去分词 | 38 |
| `X and ___` → 与 X 对称 | 36 |
| `see + 宾语 + ___` → -ing | 40 |

### 三、三条新规则（已加进网站英文页）

1. **形容词永远没有复数** —— 44 你圈的 `Europians` 错两处：加了 s，拼法 -pian 应为 -pean
2. **成对形容词不能互换** —— economic（经济上的）vs economical（节省的）；
   historic / historical、sensible / sensitive、successful / successive、industrial / industrious
3. **-sion 还是 -tion** —— 动词以 -d / -de 结尾 → -sion：divide → division、decide → decision

### 四、从下一份起，答案纸改成这个格式

```
36 [名复] divisions
37 [名]   Alternative
38 [过分] rooted
39 [形]   economic
```

**方括号里只能写一个词性，后面只能写一个词。**
方括号填不出来，就是第 2 步还没做 —— 回去看空格前后，不准看词根。
