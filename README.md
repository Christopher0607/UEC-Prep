# UEC 冲刺系统

2026 年第 52 届高中统考 · 个人备考系统。目标 7A1。

## 它是什么

一个**零成本**的备考记账系统。没有服务器、没有数据库、没有 API key —— 整站静态导出，数据存在浏览器 localStorage 里。

设计原则一句话：**网站负责记账，Claude 负责动脑。**

每个「本来该调 AI」的地方，网站改成生成一段结构化提问，你一键复制、贴进 Claude 对话。这段提问带着科目、考点、你自己的解题过程、你卡住的那一步 —— 比直接甩一张截图问「这题怎么做」得到的回答好得多。

## 功能

| 页面 | 做什么 |
|---|---|
| 总览 | 倒计时、六阶段计划、校内预考日程、每天时间块、七科现况、一键生成周复盘提问 |
| 考点 | 考点覆盖表，Book／册 → 章 → 小节 三层折叠，默认全收起。每个考点 0–3 级掌握度，不复习的可整章跳过。**7A1 的本质是没有一个盲区** |
| 错题 | 错题本 + 「只给思路不给答案」的拍照解题提问 |
| 讲题 | 费曼反向讲解。你讲，Claude 挑漏洞 |
| 英文 | 作文计划检查（Thesis 规则机器校验 + 5 Levels）、Paper 2 五个部分分别出题 |
| 华文 | 应用文骨架（公函／通告／启事）、固定套语库、格式陷阱、作文提纲检查、试卷二六部分 |
| 背诵 | Leitner 间隔重复。忘掉的卡退回第 0 格 |
| 真题 | 试卷结构（会计／经济各部分分值）+ 限时成绩走势 + 严格批阅提问 |
| 备份 | 导出 / 导入 JSON |

## 本地运行

```bash
npm install
npm run dev      # http://localhost:3401
npm run build    # 静态站输出到 out/
```

## 部署

推到 `main` 会自动触发 `.github/workflows/deploy.yml`，构建后发布到 GitHub Pages。

**首次需要手动开一次开关**：仓库 → Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。开完之后重跑一次 workflow（Actions 页 → Deploy to GitHub Pages → Run workflow），网址就是 `https://<用户名>.github.io/UEC-Prep/`。

项目站在子路径下，所以 workflow 会传 `NEXT_PUBLIC_BASE_PATH=/UEC-Prep` 给构建。本地开发不需要设，留空即可。

想改用 Netlify 也行：构建命令 `npm run build`，发布目录 `out`，不要设 basePath。

## 端到端测试

```bash
npm run build
python3 -m http.server 4173 -d out
node e2e.mjs          # 主流程
node e2e-essay.mjs    # 英文作文与 Paper 2
node e2e-chinese.mjs  # 华文应用文与作文提纲
```

覆盖：倒计时、考点导入与持久化、错题提问生成、间隔重复的记住/忘记两条分支、真题走势、周复盘提问、Thesis 规则校验（断句与漏标题都要被抓到）、移动端不横向溢出。

## 数据在哪

只在你这台设备的浏览器里。清缓存、换手机就没了 —— **每周去「备份」页导出一次**。

## 几个刻意的设计

- **拍照解题只给思路。** 给答案等于帮你跳过最后一步，而最后一步才是考场上要你自己走的。
- **错题按「概念不懂 / 套路没背熟 / 粗心 / 时间不够」归因。** 这四种的补救方法完全不同，混在一起记等于白记。
- **校内成绩标注「含作业分」。** 一旦录入限时真题成绩，就用真题的覆盖掉 —— 含作业分的平均分会骗人。
- **考点掌握度只有 3 级才算安全。** 「看得懂」不等于「会做」。
- **跳过的考点从所有计数里消失。** 会计一科就有 96 个考点，平铺出来没法用；折叠 + 跳过之后，「熟练 40/48」里的 48 才是你真的打算复习的数量，不是一个永远够不到的分母。
- **所有考纲都来自本人的课本和老师，不是猜的。** 会计 96 个考点照 Book 1–3 目录，经济 72 个照上册课本目录。
- **英文和华文的考纲来自本人的老师，不是猜的。** 分别写在 `lib/english.ts` 和 `lib/chinese.ts`。华文应用文的骨架是从老师给的 SPM 范文和讲义里逆向出来的。
- **每科的真实考试时长写死在 `lib/exam.ts`。** 取自预考时间表（预考照统考的卷长排）。做真题时一键填入，练「大概一小时」会练出错误的节奏。
- **应用文的第 3、4、5 段标成「固定套语」。** 因为在所有范文里它们确实一字不改 —— 认清这一点，应用文就从「写作」变成「背骨架换详情」。
